# Контент-завод Nutrilora

Панель для владельца, редактора и оператора публикаций. Интерфейс на русском. Первый этап работает на демонстрационных данных: API и реальные видео не подключены.

## Разделы

- Обзор — готовые ролики, публикации, расходы и ошибки
- Аккаунты TikTok — ниша, язык (русский или казахский), план роликов в день
- Производство — темы → сценарии → генерация → проверка → готово
- Редактор — сценарий, источники, предпросмотр, «Согласовать» и «На доработку»
- Календарь публикаций
- Аналитика — просмотры, реакции и стоимость ролика
- Настройки — Supabase, n8n, ElevenLabs, HeyGen, Creatomate. Без переменных сборки все статусы «Не подключено». С сессией Supabase показывает только «Сессия владельца»

Цифры пересчитываются внутри сеанса. Обновление страницы или кнопка «Сбросить сеанс» возвращают исходный учебный срез. Ключи интеграций не запрашиваются и не сохраняются.

Если при сборке заданы `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`, панель просит войти по email и читает строки владельца из Supabase. Это публичный ключ проекта, не `service_role`. Без этих переменных остаётся учебный срез, и сайт не зависит от базы. Значения задаются в переменных окружения Vercel, в чат их присылать не нужно.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`.
